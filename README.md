# Convolutional Neural Networks (CNN) Architecture Assignment

## Project Overview & Objective
This repository contains a structured Jupyter Notebook (`CNN_Architecture.ipynb`) addressing all theoretical questions and practical tasks for the Convolutional Neural Networks (CNN) assignment. It covers fundamental theory, manual matrix convolutions and pooling operations in NumPy, custom model construction using TensorFlow/Keras, regularization techniques, pre-trained architectures (VGG16, ResNet50), and full training loops with history plotting.

## Required Dependencies
To run this notebook, ensure you have the following Python libraries installed:
- `tensorflow`
- `numpy`
- `matplotlib`

You can install them via pip:
```bash
pip install tensorflow numpy matplotlib
```

## How to Run
1. Clone or download this repository.
2. Open your terminal or command prompt and launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
3. Open `CNN_Architecture.ipynb` and run the cells sequentially.

## Topics Covered
* **Theory Section:** Comprehensive explanations covering CNN definitions, filters/kernels, pooling mechanisms, backpropagation, receptive fields, tensor spaces, and landmark architectures (LeNet-5, AlexNet, VGGNet, GoogLeNet, ResNet, DenseNet).
* **Practical Section:** Hands-on implementations including manual convolution, max-pooling, ReLU functions, sequential model building, Batch Normalization, Dropout regularization, VGG16/ResNet50 summaries, history curve plotting, and custom epoch logging callbacks.
